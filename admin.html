사용 방법

  1. Claude.ai 채팅에서 아래 프롬프트를 사용해 조사를 요청합니다
  2. Claude가 응답한 JSON 결과를 복사합니다
  3. 아래 입력창에 붙여넣고 불러오기를 누릅니다
  4. 이미 등록된 식당은 자동으로 노란색 표시됩니다
  5. 체크박스로 등록할 식당을 선택하고 수정 후 일괄 등록을 누릅니다
다음 지역의 구내식당을 조사해줘. 지역: [여기에 지역명 입력, 예: 을지로] 개수: 10개 정도 중요 조건: - 반드시 외부인 출입 가능한 식당만 조사 - 사원증 필수이거나 내부 직원 전용은 제외 - 일반인 방문증 작성 후 이용 가능한 곳은 OK - 확실하지 않으면 "조건부"로 표시 아래 JSON 형식으로만 응답해줘. 다른 설명은 빼고 JSON만: [ { "name": "식당 정확한 이름", "address": "서울특별시 ...로 00 도로명 주소", "lat": 37.5665, "lng": 126.9780, "price": 7500, "hours": "11:30~13:30", "menu_type": "none", "menu_url": "", "external": "가능", "confidence": 75, "notes": "특이사항 또는 확인 필요 사항" } ] - confidence: 0~100 (정보 확실성) - external: "가능" / "조건부" - menu_type: "kakao" / "insta" / "url" / "none" - 모르는 값은 null, 가격 모르면 0
